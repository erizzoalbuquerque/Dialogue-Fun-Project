# Yellow Oyster

A tiny mini micro joke "game" for trying out [Yarn Spinner](https://yarnspinner.dev/) (it's great and a lot of fun) and experimenting with a simple to make but cohesive art style. Both things that I want to use in game jams and bigger projects in the future

Play the "game" [here](https://eduardo-rizzo.itch.io/yellow-oyster).

Mumbling characters feature was very interesting to implement also. Shout out to [this devlog](https://geolojosh.itch.io/goodlands/devlog/314373/how-to-animal-crossing-dialogue-sounds) and to [this video](https://www.youtube.com/watch?v=NaW0d7Tghw0) for the nice explanations of the basic concepts. Implementing it on Yarn Spinner was a matter of creating a custom line provider.
